========================================
  دار ليك - PWA Files
========================================

الملفات اللي كاينة هنا:
------------------------
1. manifest.json     → حطه فـ root ديال مشروعك
2. sw.js             → حطه فـ root ديال مشروعك
3. pwa-head.html     → انسخ محتواه داخل <head> فـ index.html
4. pwa-script.html   → انسخ محتواه قبل </body> فـ index.html
5. icons/            → مجلد الأيقونات (خاصك تضيف الصور ديالك)
